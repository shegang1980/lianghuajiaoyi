# 股票复盘实时面板

一个支持 A股 / 港股 / 美股 的实时行情与每日复盘 Web 面板，基于免费公开数据接口，无需 API Key。

## 功能

- **📊 行情走势**：实时报价、分时图、日K/周K/月K线（含 MA 均线）、五档盘口、成交量
- **📋 每日复盘**：全球主要指数、板块涨跌排行、A股涨幅榜/跌幅榜 TOP20
- **💼 基本面**：标的基本信息、估值指标
- 支持搜索切换标的，行情自动每 5 秒刷新

## 数据源

| 数据 | 来源 |
|------|------|
| 实时行情（A股/港股/美股） | 新浪财经 |
| K线 / 分时图 | 腾讯财经 |
| 板块 / 全市场排行 | AKShare（新浪源） |

> 数据仅供参考，不构成投资建议。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
python server.py

# 3. 浏览器打开
http://localhost:5000
```

## 使用说明

- **搜索框**：输入股票代码或名称，如 `600519`、`茅台`、`00700`、`AAPL`
- **市场切换**：A股 / 港股 / 美股
- **周期切换**：分时 / 日K / 周K / 月K
- 点击涨跌榜中的股票可直接切换查看行情

## 技术栈

- 后端：Python + Flask
- 前端：原生 HTML/CSS/JS + ECharts 5
- 数据：requests + AKShare
